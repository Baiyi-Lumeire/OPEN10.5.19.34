# 霓虹裂谷 NEON RIFT · 概念官网

一个纯前端的「游戏概念官网」UI 风格练习。以虚构企划《霓虹裂谷 NEON RIFT》为题材，
复刻都市潮酷漫画风的游戏官网版式与交互（首页大视觉、角色切换、影像资料、新闻资讯、
剧情档案、设定档案、游戏特色等整屏分节）。

- 技术栈：原生 HTML + CSS + JavaScript（无框架、无构建、无后端）
- 版权说明：本企划为虚构作品，全部配图为本地生成的原创占位图，与任何真实游戏或公司无关
- 性质：个人学习交流用途的 UI 练习，非商业、非上线产品

## 功能

- **整屏分节 + 侧边页码**：7 屏滚动式官网布局，侧边页码器/顶部导航随滚动位置高亮，
  支持上下箭头按钮与键盘（PageUp / PageDown / Alt+方向键）翻屏，浅色分节自动反色。
- **入场动画**：基于 `IntersectionObserver` 的分节渐入，低阈值触发，长页面同样可见。
- **角色介绍切换**：8 名角色立绘与档案（阵营 / 姓名 / 简介）联动切换，缩略条支持鼠标点击
  与键盘 Enter / Space 激活，带 `aria-pressed` 状态。
- **影像资料切换**：主角影像 + 4 条缩略图列表联动，切换封面、分类标签与标题。
- **新闻资讯轮播**：主推新闻 + 圆点切换，右侧资讯列表带分类标签与日期。
- **剧情档案**：4 章剧情（序章 / 第一至三章）图文联动切换，附世界观编年史时间线。
- **设定档案**：地点卡片与势力档案两组静态展示区。
- **无障碍与响应式**：语义化标签、`aria-*` 属性、键盘可达；窄屏（≤1080px）导航收起，避免标签换行。

## 用法

无需安装依赖、无需构建，任选一种方式打开：

1. **直接打开**：双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge 最新版）。
2. **本地静态服务**（可选，避免个别浏览器对本地文件的限制）：

   ```bash
   # 任选其一
   python -m http.server 8000
   # 然后浏览器访问 http://localhost:8000
   ```

> 字体通过 Google Fonts CDN 加载（Anton / Noto Sans SC）；离线环境下会退化为系统字体，不影响布局。

## 目录结构

```
index.html            # 单页入口：7 个分节 + 页脚
css/
  style.css           # 全部样式（版式、配色、响应式、动画）
js/
  main.js             # 交互脚本：分节观察、页码高亮、角色/影像/新闻/剧情切换
assets/img/
  *.webp              # 主视觉、角色立绘、影像与新闻缩略图、章节配图（原创占位图）
SECURITY.md           # 安全策略与漏洞报告方式
```

## 开发约定

- 纯静态：不引入前端框架与构建工具，保持「双击即可运行」。
- 样式集中在 `css/style.css`，交互集中在 `js/main.js`，数据（角色 / 影像 / 新闻 / 剧情）
  以数组形式内联在 `js/main.js` 中，便于增删条目。
